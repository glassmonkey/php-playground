# Versioned PHPantom WASM preview

The local preview selector contains manager-released PHPantom WASM candidates for PHP 5.6, 7.0–7.4, and 8.0–8.5. Each artifact is selected from the PHP version in the playground URL and checked against its version-specific SHA-256 and byte count before compiling. The PHPantom build identity is shared, so it does not identify the selected PHP target; the worker initialization version and registry artifact hash do.

The preview expects local files at `assets/lsp/phpantom/versioned-preview/<version>/phpantom_lsp.wasm`. These candidate binaries remain outside git pending separate UI review. The exact twelve artifacts and provenance were read from manager batch gate `manager-all12-ui-artifact-batch-gate-v1.json`; all twelve are 18,504,747 bytes and have build identity `49b9a751-phase-b-e12de794`. Each registry row also records the source patch and provenance file hash, since those differ by target in the released batch.

The PHPantom source commit is `49b9a7513ed19cbbfb79d5d08a3f3693ffb2b668`. The stubs are pinned to phpstorm-stubs commit `2049ca3cfa1feabf52db074108fe776a5713cf02`, archive SHA-256 `3ef62542d2f77ad30c7dab7dfa726e57e86dd5e3403780294119cf4f5ca6dcb7`. The reviewed Phase B patch has behavior changes; an empty `patchIds` list means there is no separate patch bundle, not that the source is unmodified. The registry's per-version source patch SHA is copied from that version's gate/provenance and is not inferred from the common build identity.

Each PHP-version change creates a fresh module worker and PHPantom/WASI instance, so document state does not carry between versions. The page caches immutable compiled modules under `(PHP version, artifact SHA-256)`. Autocomplete off creates no PHPantom worker and fetches no PHPantom artifact.

This is a local, review-only preview, not production adoption or an application-wide support claim. The released batch gate reports 20 target assertions per artifact (240 total). Its known same-name user-function PHPDoc resolve limitation remains separately recorded: function identity and insertion are retained, but resolve did not return that user's PHPDoc marker in the controlled experiment.
