# Add a lesson

Use `$php-tutorial-authoring` to add a lesson to the PHP Playground tutorial.

- PHP version(s): `<versions from src/tutorial/config.ts>`
- Slug and topic: `<slug / topic>`
- Prerequisites: `<what learners already know>`
- Visible learning goal: `<what they can do or predict>`

Choose `chapterId` for learner progression and `referenceChapterId` for PHP Manual taxonomy. Link official sources, use syntax supported by each selected runtime, and provide per-version program/output metadata. Validate and run every included version's Example, Experiments, solution/checkers, and relevant negative controls. Report unverified behavior explicitly.

Read `references/learning-design.md`. Update and review the version-resolved learning notes together with the lesson. Check structure/references, real WASM behavior, and educational meaning separately; do not infer semantic correctness from populated fields or output equality.
